# 🚀 Modern Web 3.0 Blockchain Application  

> A decentralized Web 3.0 app built using Solidity, Smart Contracts, and modern front-end technologies 

## ✨ Features  
- 💸 Ethereum transactions using Smart Contracts (Solidity)  
- 🔗 Wallet connection with MetaMask  
- ⚡ React + Vite front-end with Tailwind CSS  
- 🧰 Hardhat for compiling and deploying contracts  
- 📊 Transaction history with GIPHY API integration  
- 🌐 Easily deployable on Vercel or Netlify  

## 🧩 Tech Stack  
**Blockchain & Smart Contracts**  
- Solidity  
- Hardhat  
- Ethers.js  

**Front-End**  
- React.js (Vite)  
- Tailwind CSS  
- Context API  

**Other Tools**  
- MetaMask  
- GIPHY API  
- Alchemy / Infura RPC node
